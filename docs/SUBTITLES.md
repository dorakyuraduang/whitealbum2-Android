# 内置正篇语音字幕

从 `0.2.39-shared-aot` 起，Windows x64 与 Android ARM64 共用同一套
正篇语音字幕实现。数据来自
[nxs7/WA2-CHS-Subtitle-Patch](https://github.com/nxs7/WA2-CHS-Subtitle-Patch)
固定提交的根目录 `script/sub.yaml`，包含 46 段音频、315 条字幕。
默认生效，不需要把原补丁 DLL、`subtext.dat` 或 `subfont.tga` 放到资源目录。
这是为原游戏中只有声音的片段补充文字，不是重新汉化全部剧情。

`0.2.58` 起可在安卓启动页关闭“正篇补充中文字幕”，默认仍开启。
它独立于脚本和配套字库选择，关闭不会隐藏剧情正文或停掉语音。
Windows 使用同一实现，参数为 `--no-chinese-subtitles`。
选项保存在安卓所选游戏目录，下次启动生效；关闭后不做字幕参数读取、
字幕选择或字图上传。语言资源切换见 [LANGUAGE_RESOURCES.md](LANGUAGE_RESOURCES.md)。

`0.2.59` 起还可选择玩家自己的 `sub.yaml`；默认仍用这里描述的内置数据。
同一个字幕开关控制所选来源。外置格式严格校验，外置整份替换内置轨道，
新字符通过离屏字体适配器生成字图后使用同一绘制路径。
参见 [EXTERNAL_SUBTITLES.md](EXTERNAL_SUBTITLES.md)。

整个 `SpecialContents` 字幕集都没有导入、编译或打包。根目录正篇字幕中的
`scene=9500` 是原游戏人物采访的编号，仍按该文件的内容保留；不会加入
Special Contents 的广播剧、附加歌曲等数据。

语音使用音频自身的场景编号与 ID；复用到别的剧情场景时仍能匹配。音效使用
音效 ID。现有静态音频函数完整执行后才发送字幕事件，相同通道停止时清除字幕。
没有增加逐指令钩子，也没有跳过、改写原音频函数。时间采用原补丁的毫秒区间，
延迟提交一帧时直接选取当前区间，避免逐句追赶已经过期的文字。

字幕状态由独立的原生服务持有，运行时与兼容进程的原有类布局不变，继续核对
历史对照库的 ABI。运行时仅首次解析服务绑定，后续音频事件和绘制不查询注册表。

显示使用当前游戏的等比例视口，白字、黑描边、顶部居中，过长的字幕自动换行。
字幕变化或视口调整时才重建几何；使用时上传一份只含 891 个字符的共享字图，
不逐帧读取字幕文件、生成字体或重新上传字图。原游戏 PAK 保持外置。

`0.2.40` 修正后台缓冲区大于实际显示区域时的字幕缩放与位置。例如游戏只显示
1920×1080 后台中的 1280×720 区域时，旧换算会将字幕放大 1.5 倍，并把横向
中心从 640 移到 960，导致右侧文字裁切。现在完整的 1280×720 字幕画布直接
适配最终可见游戏视口，统一缩放、顶部居中；不再经过后台分辨率和源裁切的二次
换算。换行继续按字幕画布计算，不让黑边参与排版。内存回归检查覆盖 16 种后台、
裁切、窗口缩放及手机横竖屏组合，逐字检查全部 315 条字幕的最终位置和大小。

许可和来源见 [third_party/wa2_subtitles](../third_party/wa2_subtitles/README.md)。
内存检查覆盖全部字幕时序、原始音频 ABI、停止/覆盖、字图和布局，着色器使用
桌面 GL 与 GLES3 的离线编译/链接检查。按项目约束没有启动游戏、模拟器或读取
屏幕，手机实际显示、音画同步及完整剧情兼容性仍需实机验证。

## SC 的字幕开关

从 `0.2.122-special-aot` 起，SC 配置页与本体使用相同的「补充字幕」开关
和字幕来源选择。总开关同时控制默认来源和自选来源，关闭后不读取字幕
资源、不上传字图，也不读取字幕事件参数。FPS、60 帧限制和长按快进同样
通过当前程序的已保存配置传入独立运行会话；原有设置保留。

SC 默认来源是用户授权目录中的 `subtext.dat`、`subfont.tga`、`songfont.tga`。
它们保持外置，不复制到应用内部，不编进 APK 或公共源码。原 SC 数据含
广播剧、第二行文字及歌曲字幕，解码为同一个共用字幕目录，按时间边界
合并成多行，复用本体的计时、字图上传、视口换算和绘制路径。自选字幕
仍使用项目现有的固定 YAML 或 Todokanai 格式，以 BGM 编号为 scene、
章节编号为 id；默认二进制来源与这两种自选文本格式分开校验。

SC 使用 BGM／章节／停止事件，未套用本体普通语音函数的地址。布局与格式
依据固定版本的 [SC 原字幕补丁源码](https://github.com/nxs7/WA2-CHS-Subtitle-Patch/tree/bb3cbc2f459549f8afbcb56cafd4b861d763bd29/SpecialContents)，
实现采用本项目的有界解析和共用呈现管线；未执行该项目的 DLL 或脚本。
三个 SC 源函数的完整缓存指令和返回点受 SHA 绑定，仅在原 RET 成功后
通知字幕，保留返回寄存器及栈 ABI。自动章节切换沿用 1 秒延时，尚未到达
开始时间的字幕保持隐藏；普通效果的插值调用在未跟踪广播剧时不读取字幕参数。

既有 0.2.121 SC 配置保留原开关值；需要时在 SC 页勾选「补充字幕」。若所选
目录缺少默认来源文件，启动检查会指出缺少哪份文件，可选择外置字幕或关闭
补充字幕。关闭该功能不会隐藏原游戏正文或关闭声音。手机实际显示和音画
同步由用户手动运行验证，组件检查不证明整段剧情兼容性。

0.2.122 已保留数据安装到授权手机；用户手动确认四项设置齐全、字幕正常。
同次 SC 应用计数记录字幕开启、23 条轨道和一次 BGM 开始事件。全场景音画
同步和自动章节切换仍需继续实机覆盖。
