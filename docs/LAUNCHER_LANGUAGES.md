# 启动页界面语言

安卓启动页提供独立一行的“界面语言 · 当前语言”文字按钮。
从 `0.2.73-shared-aot` 起，未手动选择时自动匹配手机系统首选语言，
没有对应翻译（或无法取得语言）时使用英文。手动选择后立即更新按钮、开关、
提示和启动页自己的选择对话框，并记住该选择；已有手动选择也会保留并优先使用。
不必先授权游戏目录。语言列表使用各语言自己的名称，便于选错后重新找到。

阿拉伯语、波斯语、希伯来语、乌尔都语使用从右向左的界面布局，间距按起始
方向排列。游戏窗口和原版控件仍使用原坐标方向。切换界面语言不改变系统或
进程的默认 Locale、资源解码、游戏语言、字幕来源、存档及其编码。

这是启动器的界面翻译。“选择游戏语言”独立选择中、日、英、乌克兰语脚本与字库，见
[游戏语言设置](LANGUAGE_RESOURCES.md)。系统文件选择器由 Android 提供，
使用系统自身的语言；底层诊断、资源/解码错误的具体详情可能保留原文。

界面语言保存在应用自己的 `launcher-ui` 首选项中，因而首次选目录前也可
使用。游戏设置与启动开关使用所选目录的 `native-launcher.wa2cfg`，
界面语言独立保存。自动匹配不会写成手动偏好，未手动选择的用户后续更改系统语言时，
下次启动器创建界面会重新匹配；未识别的界面语言记录回到英文。

启动页改为顶部对齐，避免短表单被垂直居中而产生大块留白。`0.2.64` 按
系统栏和刘海的四边安全区域避让，再在顶部保留 4 dp；底部也避开导航区域。
内容宽度根据当前窗口安全区域计算，RTL 不交换物理刘海边距。原有紧凑行
和至少 48 dp 的点击高度保留，小窗口、大字体与长错误仍可滚动。

“显示右上角菜单”默认开启，关闭后下次进入游戏时隐藏按钮。双指轻点仍可
临时显示或隐藏，重新进入游戏后按已保存的偏好初始化。每个功能各占一行，
长文字可自动换行。

`0.2.66` 在游戏语言选项下增加两行脚本包、字库包路径提示，`./` 指当前
选择的游戏目录。两行提示也随界面语言翻译，文件名由游戏语言配置决定。

纯状态检查覆盖 28 个完整字典、1232 条文字、308 个格式化调用、4 个 RTL
语言、25 个地区/语言标记解析、自动匹配及手动选择优先级，检查切换界面文案
不改变游戏配置字节和进程默认 Locale。简繁中文优先尊重 `Hans`/`Hant`，
未指定字形时按地区区分。
两套 Java 适配器与 DEX 编译不等于设备上的排版或翻译质量验收；本次未
启动游戏、操作界面或读取屏幕。复杂文字的系统字体显示仍需设备实测。
