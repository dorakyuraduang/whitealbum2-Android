# 启动页界面语言

`0.2.63-shared-aot` 的安卓启动页在右上角提供 🌐 按钮。默认简体中文，
选择后立即更新按钮、开关、提示和启动页自己的选择对话框，并自动记住选择。
不必先授权游戏目录。语言列表使用各语言自己的名称，便于选错后重新找到。

阿拉伯语、波斯语、希伯来语、乌尔都语使用从右向左的界面布局，间距按起始
方向排列。游戏窗口和原版控件仍使用原坐标方向。切换界面语言不改变系统或
进程的默认 Locale、资源解码、游戏语言、字幕来源、存档及其编码。

这是启动器的界面翻译。按钮“游戏”独立选择中文或日文脚本与字库，见
[游戏语言设置](LANGUAGE_RESOURCES.md)。系统文件选择器由 Android 提供，
使用系统自身的语言；底层诊断、资源/解码错误的具体详情可能保留原文。

界面语言保存在应用自己的 `launcher-ui` 首选项中，因而首次选目录前也可
使用。游戏设置与启动开关仍使用所选目录的 `native-launcher.wa2cfg`，
没有升级该格式或覆盖其中的选择。未识别的界面语言记录回到简体中文。

启动页改为顶部对齐，顶部内边距为 4 dp，避免短表单被垂直居中而产生大块
留白。原有紧凑行和至少 48 dp 的点击高度保留，小窗口、大字体与长错误
仍可滚动。

纯状态检查覆盖 28 个完整字典、1148 条文字、252 个格式化调用、4 个 RTL
语言及地区别名，检查切换界面文案不改变游戏配置字节和进程默认 Locale。
两套 Java 适配器与 DEX 编译不等于设备上的排版或翻译质量验收；本次未
启动游戏、操作界面或读取屏幕。复杂文字的系统字体显示仍需设备实测。
