# 外置 sub.yaml

从 `0.2.59-shared-aot` 起，安卓启动页的“字幕来源”可以在“内置字幕（默认）”
与玩家选择的外置字幕文件之间切换。“正篇补充字幕”仍是同一个总开关，
同时控制内置和外置字幕；没有增加第二个字幕开关。默认继续使用内置中文。

选择步骤：

1. 点击“字幕来源 → 选择外置 sub.yaml”，在系统文件选择器中选择文件。
2. 等待编码、结构、音频编号、时间轴及字形校验通过。失败会显示原因和
   出错行号（适用于语法错误），并保留原来的选择。
3. 从启动页重新开始游戏。每次启动会读取并重新校验文件；修改后的错误
   不会被旧校验结果掩盖。缺失文件或失效授权会提示重新选择。

字幕文件不必叫 `sub.yaml`，但内容必须符合下面的格式。它可以放在通过
系统文件选择器授权的任意位置，不需要放入 APK 或覆盖原版 PAK。
文件只读；设置和文件引用保存在所选游戏目录的 `native-launcher.wa2cfg`。
系统需支持持久读取授权。取消选择、错误文件和校验失败都不改动原选择。
点击“内置字幕（默认）”即可恢复内置来源。

Windows 使用同一实现，通过参数选择，路径可为绝对路径或相对游戏目录的路径：

```text
WA2_SDL2_x64.exe --root <游戏资源目录> --subtitles sub.yaml
```

省略 `--subtitles` 使用内置字幕；`--no-chinese-subtitles` 关闭当前字幕来源。

## 支持的格式

采用此前汉化字幕项目根目录 `script/sub.yaml` 的普通字符串子集，UTF-8
编码，可带 UTF-8 BOM，支持 LF/CRLF 换行。文件最多 1 MiB：

```yaml
soundEffect:
    - id: 8365
      content:
          - begin: 0
            end: 5000
            text: 这是自定义字幕。
voice:
    - scene: 1001
      id: 1
      content:
          - begin: 1000
            end: 4000
            text: 请填写与音频对应的文字。
```

`begin` / `end` 是相对该段音频开始的毫秒，不是影片的全局时间。
`soundEffect` 用音效 ID，`voice` 用场景编号和语音 ID。示例中的 voice
编号只演示格式，实际编号和时间应来自对应音频；可参考仓库中固定的
[正篇字幕源文件](../third_party/wa2_subtitles/sub.yaml)。内置数据没有改变。

两个根分组都必须存在，可以有一个空分组，至少需要一条有效字幕。
编号为 0–65535 的十进制整数，voice 场景为 1–65535。
时间必须满足 `0 ≤ begin < end ≤ 4294967295`，同一音频内按时间排列，
相邻时间段可首尾相接，不能重叠。场景/音频组合不可重复。
文字每条最多 512 个 Unicode 字符；最多 1024 段音频、8192 条字幕、
131072 个文字字符、1536 种不同字符。

缩进和字段与示例一致。支持空行与整行 `#` 注释；不接受额外字段、
重复字段、缺少内容、YAML 标签/对象/引用/锚点、数组、带引号或折叠/多行
字符串、嵌入文件和 Special Contents 分组。SRT/ASS 不能直接选用，因为
没有本功能所需的场景与音频映射。检查不只是检查后缀或文件名。

外置文件**替换整份内置字幕**，不会混入未翻译的内置轨道。
没有写进外置文件的音频不显示补充字幕，不影响剧情对白或音频播放。
游戏语言选择与字幕来源仍独立；选择日语也可保留或关闭中文字幕。

## 字体与实现边界

文字全部由原内置字图覆盖时复用原字图，位置、颜色和描边保持原实现。
新增字符使用平台字体适配器在内存中生成一次字图，再交给同一套 C++
排版、描边、播放时序和 GPU 提交。Android 使用系统字体，Windows 使用
Microsoft YaHei；不依赖截图、不读取屏幕。缺字或超过字图尺寸时明确拒绝，
不会以缺字方框代替并宣称校验成功。复杂文字塑形和所有 Unicode 字符的
跨设备覆盖不作保证；Windows 新字形适配器目前支持 BMP 字符。
字图只在需要时上传，不逐帧读 YAML、生成字体或新增 Java 字幕覆盖层。

安卓选择时与实际运行时、Windows 使用同一个严格 C++ 解析器。
启动器只为校验加载本地库，不进入游戏、不打开窗口或音频设备。
外置文件启动时重新读取，验证通过后建立只读播放数据。
`0.2.65` 使用 v6 启动设置，最多 4112 字节；仍兼容最大 4372 字节的旧
v3 记录及 v1/v2/v4/v5 记录，保留字幕来源。不保存字幕正文或字图。
回退旧 APK 前可备份该配置，再让旧启动器重新生成。

组件检查逐条比较原有全部 315 条字幕和 6462 个字符，覆盖 BOM/CRLF、
不合法编码、字段和时间冲突、大小边界、播放器切换、字图和原音频事件桥接。
两平台编译同一份静态游戏源码。没有启动游戏、模拟器或操作/读取画面；
手机字体显示、文件提供者授权与实际剧情同步仍需玩家实测。
