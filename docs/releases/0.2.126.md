## 中文

### 0.2.126 更新内容

- 新增 SC 入口，可在同一个应用中切换本体和 SC，分别保存设置。
- SC 支持中文、日文和英文，补充字幕随所选游戏语言自动读取。
- 优化 SC 剧情、快进、粒子效果和存档、设置页的卡顿，修复开头 Logo 播放问题。

### 版本说明

此版本为静态重编译版，整体体验与 PC 原版基本一致。
不过，目前版本尚未经过充分测试，可能存在一些未知问题。
如果遇到 Bug 或其他异常，请直接在 GitHub Issues 中反馈，也可以下载 0.3 版 Godot 版本作为替代。

## English

### What's new in 0.2.126

- Added Special Contents (SC) alongside the main game, with separate settings in one app.
- SC supports Chinese, Japanese and English, with supplementary captions selected automatically for each language.
- Optimized SC story playback, fast-forwarding, particle effects and save and settings screens; fixed the opening Logo playback.

### About this version

This is the static recompilation version, offering an experience largely consistent with the original PC release.
However, this version has not yet been thoroughly tested, so some unknown issues may remain.
If you encounter any bugs or other problems, please report them through GitHub Issues. You can also download version 0.3 of the Godot port as an alternative.
