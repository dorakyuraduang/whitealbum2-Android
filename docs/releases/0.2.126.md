# 0.2.126 本体 / SC 整合版 · Main + Special Contents

2026-11-21 · Android ARM64 · `0.2.126-special-aot` · version code 129

## 中文

一个 APK 现在提供本体和 Special Contents（SC）两个入口，分别选择资源目录、
保存启动配置，并在独立进程运行。SC 支持中文、日文和 English；本体继续使用
已验证的 `0.2.108-shared-aot` 运行库。

相较于上次公开发行 0.2.83，本次整合了后续本体文字／绘制／粒子和存档读取
改进，以及 SC 的音频解码、图片缓存、文字排版、绘制、天气和重复配置写入
优化。SC 开头 Logo 和存档页路径也已修复。手机性能收益仍需同场景、同设置
测量；组件检查不代表全剧情兼容性。

### SC 英文与字幕

- 对应 **White Album 2 Special Contents full patch v1.0**。英文补丁与中文 SC
  共用同一套静态游戏函数，英文界面、脚本、字体和窗口文字使用对应资源。
- SC 的 FPS 显示、60 FPS 限制、长按快进、补充字幕和菜单开关独立保存。
- **SC 不再提供外置字幕选择。** 中文自动读取 `subtext.dat` 和两张字图；
  English 自动读取 `subtext_en.dat`。旧 SC 字幕 URI 会清除，其余配置保留。
  本体的自选字幕功能继续保留。
- 英文准备工具从自备补丁 MKV 中提取字幕并匹配原音轨，得到 24 个章节、
  2972 条字幕时间区间。重新编码的一段音频已校准 3970 毫秒偏移。
- 日文补充字幕对应 `subtext_ja.dat`，此英文补丁未提供；缺少对应版本文件时，
  补齐文件或关闭补充字幕。

### 安装与下载文件

要求 Android 8.0+、ARM64、OpenGL ES 3.0。安装
**`WA2-arm64-0.2.126-special-aot.apk`**，已有同包应用可保留数据覆盖安装。
启动页先选本体或 SC，再选该作品自己的完整资源目录，PAK 保持原名和打包状态。
存档、配置和游戏资源继续放在授权的外部文件夹。

英文用户另下载 **`WA2-SC-English-resource-tools.zip`**，解压后用 Python 3.9+
运行下列命令，只需标准库、自备完整英文补丁 ZIP 与原始 SC 资源，不需要
私有开发缓存或编译器：

```powershell
python scripts/prepare_special_english_resources.py "path/to/White Album 2 Special Contents full patch (v1.0).zip" --base-root "path/to/original SC folder"
```

将输出目录 `out/special-english-resources/` 中的 `en.pak`、`subtext_en.dat`、
`mv000_en.pak`、`credits_en.pak` 四个新增文件放入手机所选 SC 目录，再选择
**SC → English**。原有资源继续保留。补丁 ZIP 的独立 PDF、HTML 和备用 TXT
不会作为游戏场景导入。发行附件不包含游戏 PAK、原 EXE 或 SC 字幕文字。

**`WA2-0.2.126-special-aot-relink.zip`** 提供匹配本体和 SC 的 FFmpeg 源码、
构建配置、应用链接材料及许可声明，供替换库后重新链接使用，无需放入手机。
**`SHA256SUMS.txt`** 提供三个发行附件的 SHA-256。

## English

This release provides **Main / Special Contents (SC)** in one Android ARM64
APK, with separate resource folders, launcher profiles and runtime processes.
SC supports Chinese, Japanese and English. Main retains its verified
`0.2.108-shared-aot` runtime.

Since public release 0.2.83, the package incorporates subsequent Main text,
drawing, particle and save-loading changes, plus SC audio decoding, image reuse,
text, drawing, weather and configuration-I/O work. It also includes SC Logo and
save-page fixes. Android performance gains require comparable on-device scenes
and settings; component checks do not establish complete gameplay compatibility.

### English SC and automatic captions

- Supports **White Album 2 Special Contents full patch v1.0** using the same
  static game functions as Chinese SC, with localized interface, script, font
  and window-resource data.
- SC independently saves FPS display, optional 60 FPS limit, hold-to-skip,
  extra-caption and menu settings.
- **SC has no external-caption picker.** Captions follow the selected game
  language: Chinese uses `subtext.dat` and its atlases; English uses
  `subtext_en.dat`. Legacy SC caption URIs are cleared; other settings remain.
  Main retains its external-caption picker.
- The preparation tool maps patch MKV captions to the original audio/chapter
  timeline: 24 chapters and 2,972 caption intervals. The re-encoded audio segment
  has a measured 3,970 ms correction.
- Japanese supplementary captions use `subtext_ja.dat`, which this English
  patch does not supply. Provide matching files or disable extra captions.

### Install and prepare resources

Requires Android 8.0+, ARM64 and OpenGL ES 3.0. Install
**`WA2-arm64-0.2.126-special-aot.apk`** in place over the same AOT package to
retain its data. Select Main or SC before choosing its complete external game
folder. Keep original PAK filenames and Main's `IC` layout.

For English SC, extract **`WA2-SC-English-resource-tools.zip`** and run the
Python command above with your own full English patch ZIP and original SC
folder. Python 3.9+ standard-library modules are sufficient; no compiler or
private AOT cache is needed. Copy `en.pak`, `subtext_en.dat`, `mv000_en.pak` and
`credits_en.pak` from `out/special-english-resources/` into the SC folder selected
on your phone, retain original resources, then choose **SC → English**.
Standalone patch PDFs, HTML links and backup TXT novels are not imported as
game scenes. No original game EXE, PAK or external SC caption text is supplied.

**`WA2-0.2.126-special-aot-relink.zip`** supplies matching Main/SC application
link materials, FFmpeg source/configuration and notices. It is for replacing
compatible libraries and relinking, not phone installation.
**`SHA256SUMS.txt`** lists hashes for the three release assets.

29 C++ component groups, both Android Java adapter sets and 14 pure-state checks
passed. Windows and Android compile the same 21 generated SC C++ files. English
image identity, caption-language guards and native image/audio admission were
checked. The SC relink recipe, public exports, SONAME and 16 KiB LOAD alignment
were verified without executing a game.

The APK was installed in place on the authorized phone, preserving application
data and matching its installed version and hash. Game launch, UI operation and
screen access were not performed. Complete English gameplay, on-device caption
display/synchronization and comparable frame-rate measurements remain pending.
Please report issues with the version and application diagnostics.
