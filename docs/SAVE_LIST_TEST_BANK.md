# 00–99 手动存档测试包

用一份完整的原版格式手动存档，逐字节复制生成 `save_00.sav` 到 `save_99.sav`，用于排查“继续游戏”列表在槽位增多后无法打开的问题。100 个槽位使用同一剧情点、同一缩略图及同一描述，不修改存档内部结构。

## 生成

```powershell
python scripts/make_save_test_bank.py --source "你的存档目录/save_00.sav" --output "out/save-list-test-00-99"
```

输出文件夹必须尚不存在；旁边同时生成同名 ZIP。脚本验证原版手动存档头、100 个文件的 SHA-256 和 ZIP CRC，并确认原样本未变化。原存档内容、测试存档和压缩包不提交到公开仓库。

## 使用

1. 先把现有存档备份到游戏目录之外，避免测试文件覆盖真实进度。
2. 解压 ZIP，将其中的 `save_00.sav` ～ `save_99.sav` 复制到正在测试的存档目录，不必复制说明和校验文件。
3. 普通模式测试请关闭测试模式。若专门测试测试模式，则放到所选游戏目录的 `test-mode/`。

**0.2.76 及以后**：普通模式只读取 `<游戏目录>/Documents/Leaf/WHITE ALBUM2/`，请把测试文件放在这里，根目录旧存档会被忽略。0.2.75 的行为是根目录优先，测试该旧版时仍按旧版位置放置。测试包本身不更新游戏程序。

可先放入 10 个，再增加到 100 个，比较“继续游戏”页面是否能够打开。测试包不含 `Sys.sav`、启动器设置或 INI，也不会修改它们。游戏页面及读档后的剧情兼容性需要玩家手动验证；脚本不会启动游戏、操作界面或读取屏幕。
