# 脚本、字库与中文字幕设置

`0.2.58-shared-aot` 的安卓启动页可以分别选择剧情脚本 PAK 和配套字库 PAK，
也可以关闭内置正篇补充中文字幕。初始选择为“当前资源（默认）”，保持已有
脚本、字库和资源优先级，中文字幕默认开启。升级会保留 FPS、长按快进和
测试模式，不要求重设游戏文件夹。

1. 把其他语言的兼容 PAK 放入已选择的游戏目录或其 `IC` 子目录。
   可用 `script-en.pak`、`font-en.pak` 等不同文件名保留多组语言资源，
   不必覆盖当前文件。包文件名使用 ASCII 字母、数字、点、下划线或短横线；
   游戏目录本身名称不限。
2. 在启动页点击“刷新资源列表”，再分别点击“剧情脚本”和“游戏字库”，
   选择配套文件。每个选择器都有“当前资源（默认）”，可随时恢复。
3. 按需设置“正篇补充中文字幕”，点击“开始游戏”。更改在下次从启动页
   进入游戏时生效；游戏中的当前运行会话使用启动时已保存的设置。

脚本选择替代逻辑资源 `ck-gal.pak` / `script.pak`，字库选择替代
`fon.pak` / `fnt.pak`。已有的对应 IC 包也使用选定资源；不存在的 IC 包
不会被创建。空选择保持原始资源不变，脚本和字库可独立恢复。
`patch.pak` 的原有成员优先级保持有效，包含同名脚本或字图的旧补丁可能
覆盖所选语言；此类补丁需由玩家更换为配套版本。

这里选择的是游戏资源语言，并不会翻译文本。语言包须符合现有脚本二进制
格式、文本编码、成员名称与字库图集顺序。脚本包至少要有匹配的 `.bnr` /
`.txt`，字库包要有现有引擎需要的四张原格式字图；普通 TTF/OTF 字体不能
直接使用。启动前验证包索引和所需名称；不解包脚本、不复制整个 PAK，
原文件保持只读。基本格式检查不等同于证明任意第三方翻译包全流程兼容。
原存档继续使用既有格式；不同脚本版本的行号和场景可能不兼容。

“正篇补充中文字幕”仅控制内置 nxs7 正篇语音/音效补充字幕，不会隐藏剧情
对白、不改变语音，也不会加入 Special Contents。它可以配合任意脚本语言
独立开关。关闭时不选取字幕、不读取额外字幕事件参数、不上传字幕字图。
说明和来源见 [SUBTITLES.md](SUBTITLES.md)。

安卓设置写入所选游戏目录中的 `native-launcher.wa2cfg`，每个目录独立，
写入在后台串行完成。旧版 16 字节设置可读取并保留原开关，新版格式最多
272 字节，包含脚本/字库相对文件名和校验码，不保存 PAK 内容。
缺失的选择会提示修改设置，损坏配置不会静默覆盖。新版写出的配置不能由
旧版启动器读取；回退 APK 前可备份该文件，再让旧启动器重新生成设置。

Windows 使用相同共用加载和字幕代码，通过参数选择：

```text
WA2_SDL2_x64.exe --root <游戏资源目录> --script-pak script-en.pak --font-pak font-en.pak --no-chinese-subtitles
```

省略参数保持当前资源和开启字幕；`--chinese-subtitles` 可显式开启字幕。
Android 只把启动设置转成这些相同参数，没有单独的游戏逻辑或渲染分支。

内存/自建文件检查覆盖别名、根目录与 IC、文件 API、独立描述符、只读约束、
无效选择未发布、旧配置迁移、并发设置写入及全部字幕的开关时序。
两平台编译同一份 AOT 与共用源码。未启动游戏、模拟器、操作界面或读取屏幕，
第三方语言包的实际显示和剧情兼容仍需玩家实测。
