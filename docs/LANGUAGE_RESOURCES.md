# 游戏语言与字幕设置

`0.2.60-shared-aot` 将安卓启动页的自定义脚本、字库选择合并为“游戏语言”。
默认简体中文，玩家可切换日本語，程序自动使用对应资源与内置姓名：

| 游戏语言 | 根目录脚本 | 根目录字库 | 内置姓名示例 |
| --- | --- | --- | --- |
| 简体中文（默认） | `ck-gal.pak` | `fon.pak` | 春希、和纱、雪菜 |
| 日本語 | `script.pak` | `fnt.pak` | 春希、かずさ、雪菜 |

将对应的原版 PAK 放入选择的资源目录根目录，并保留原有 `IC` 子目录。
游戏目录的名称不限。启动页只需选择语言，不再分别设置文件路径；下次启动
游戏时生效。缺少对应文件会显示具体文件名，不会悄悄改用另一种语言。
这项选择控制剧情脚本、字库与默认姓名，并不自动翻译图片中的菜单文字。

两个语言配置由 Windows、Android 共用 C++ 加载层处理：逻辑脚本名
`ck-gal.pak` / `script.pak` 都指向所选脚本，逻辑字库名 `fon.pak` /
`fnt.pak` 都指向所选字库；已有对应 IC 包也使用该资源，不创建不存在的
IC 包。`patch.pak` 的既有优先级保留；其中同名脚本或字图需要与语言配套。
启动时只验证 PAK 索引及必需成员，不把包解压复制到 APK 或私有存储。

日文原程序与已验证的中文 AOT 缓存具有相同的两张字形范围表和索引函数。
区别在于配套字图内容和 32 个默认姓名槽中的 20 个字符串。日语模式只在
初始内存加载后、游戏运行前设置这 20 个姓名指针；代码、字形范围表及
原字符串保持不变。中文版默认不修改姓名。原有配置、存档内已保存的姓名
不在文件中批量改写；切换语言后的旧存档、第三方修改脚本的兼容性仍需实测。

“正篇补充字幕”与游戏语言独立，默认开启并使用内置中文字幕，也可以选择
外置 `sub.yaml`。它只控制语音/音效补充字幕，不隐藏剧情对白或改变语音，
不加入 Special Contents。见 [字幕范围](SUBTITLES.md) 和
[外置字幕格式](EXTERNAL_SUBTITLES.md)。

启动设置保存在所选游戏目录的 `native-launcher.wa2cfg`，后台串行写入。
v4 记录保存语言枚举、原开关与外置字幕 URI，最大 4112 字节；仍能读取
最大 4372 字节的旧 v3 记录。旧 v1/v2/v3 设置保留 FPS、长按快进、测试模式
和字幕设置，成功保存后升级为 v4：

- 旧脚本选 `script.pak` / `IC/script.pak` 时转为日语，同时配套 `fnt.pak`。
- 旧脚本未选择、字库为 `fnt.pak` / `IC/fnt.pak` 时也转为日语。
- 其他旧组合转为默认中文，移除任意自定义脚本/字库路径。

损坏配置明确报错，写入失败保留待重试状态。每个资源目录独立保存，切换
语言保留其他开关和字幕来源。回退不支持 v4 的旧 APK 前可备份配置，再让
旧启动器重新生成；游戏存档不因启动器格式升级而转换。

Windows 使用相同的语言配置：

```text
WA2_SDL2_x64.exe --root <游戏资源目录> --language ja-JP
WA2_SDL2_x64.exe --root <游戏资源目录> --language zh-CN --no-chinese-subtitles
```

省略 `--language` 默认中文。旧 `--script-pak` / `--font-pak` 参数明确拒绝，
提示改用语言选项。不支持的语言也明确报错；这里没有通用翻译或 TTF/OTF
剧情字体替换功能。

内存与合成文件检查覆盖两套自动配对、目录别名、原文件 API、无效选择不
发布、32 个默认姓名槽、旧设置迁移与写入重试。两平台编译同一份静态游戏
源码。组件检查不等于全剧情验证；未启动游戏、操作界面或读取屏幕。
