# 乌克兰语补丁与 Todokanai 字幕

## 0.2.83 起：直接保留 PC 补丁布局

在启动页选择 **Українська**，将原版游戏资源和 UA 0.1.5 补丁的
`en.pak`、`script/`、`IC/script/`、`fnt/` 按 PC 相同布局放在所选目录。
保留原版 `script.pak`、`IC` 资源。无需生成 `ua.pak` 或 `font_ua.pak`。
外置脚本、字图优先使用，缺少的图集从 `en.pak` 的 `fnt` 分组读取。
补丁 EXE/DLL 不参与运行，姓名、引号和文字推进仍使用共用的乌克兰语适配。
字幕继续通过“字幕来源”手动选择。

既有乌克兰语启动配置仍可读取。此前生成的 `ua.pak`、`font_ua.pak`
及其外置目录继续支持；它们的格式、准备方法记录在下面的旧布局说明中。
这里核对的是用户提供的 0.1.5 补丁，不推断其他版本的 EXE 或字库兼容性。

## 旧版独立 PAK 布局

从 **0.2.70-shared-aot** 起，在启动页「游戏语言」选择 **Українська**。
Windows 使用同一份游戏逻辑与资源配置：`--language uk-UA`。
完整剧情和实际手机显示仍需玩家测试；组件检查不代表全部剧情兼容。

## 文件放置

将准备好的两个文件放在玩家所选游戏目录根目录，目录名称不限：

| 文件 | 内容 |
| --- | --- |
| `ua.pak` | 乌克兰脚本、主篇/IC 的独立脚本分组，以及补丁界面、背景和原补丁后备脚本 |
| `font_ua.pak` | 配套的四张字体图集，大号图使用补丁外置字图，小号图来自同一份补丁 |

保留完整原版 PAK、原有 `IC` 子目录和日文原版 `script.pak`。
如游戏资源版本提供 `IC/script.pak`，也应保留它作为 IC 基础数据后备；原有
`patch.pak` 优先级保留，其他语言补丁中同名内容可能发生冲突。
两个新文件不会覆盖中文或英文资源，也不要求把游戏 EXE 放进目录。

主篇与 IC 可以存在同名场景。准备工具将其放在 `script` 与
`ic/script` 两个 KCAP 分组内；共用适配器按原请求的脚本目录选择分组，
而不是把两份同名脚本合并。所有原版资源继续按需读取，PAK 不进入 APK。

## 从作者原 ZIP 准备资源

输入：[WHITE-ALBUM-2-UA 0.1.5](https://github.com/ZandERIncUB/WHITE-ALBUM-2-UA/releases/tag/v0.1.5)。

工具目前只接受已核对的 0.1.5 原包，SHA-256：

```text
8b57eb7963a89280c61e44a125d7941c859e506220d6281469e5cf89d1b8cf96
```

在已有项目构建环境中，先构建离线编码器，再运行准备工具：

```powershell
cmake --build build/shared-aot-refresh-x64 --target wa2_prepare_lzss --parallel 1
python scripts/prepare_ukrainian_resources.py --zip "补丁 ZIP 的路径" --out "输出目录" --encoder build/shared-aot-refresh-x64/wa2_prepare_lzss.exe
```

编码器只用于资源准备，不链接进游戏。工具逐项检查 439 个文件的散列，
保留脚本原字节与配对关系，复制无需改变的已压缩成员，并用游戏原 LZSS
格式压缩两张大号字图。已有输出会被拒绝覆盖，原 ZIP、原游戏资源、存档和
配置不改动。安装器、EXE、DLL 不会执行，也不会加入输出。

本次实际生成的大小：`ua.pak` 129,322,476 字节，
`font_ua.pak` 14,382,839 字节。分享字库时应同时附上原补丁的
`OFL_OpenSans.txt`，并遵循原游戏、补丁与字体各自的许可；游戏资源不提交到代码仓库。

单独准备资源不需要完整 AOT 输入；也可以用普通 C++20 编译器直接编译
`scripts/pack_lzss.cpp`，再将得到的编码器路径传给 `--encoder`。

## 字体、姓名与文本行为

两张字形范围表以及全部 65,536 个字符编号的查找结果与既有 AOT 一致。
字库使用自定义单字节字形编码，部分脚本还含高位字符；不能当作普通 UTF-8
译文批量转码，也不能用改名的中文字库代替。

共用代码按这份补丁设置七个已改变的默认姓名，其余姓名保留日文基线。
存读档等七处提示使用与该字库匹配的乌克兰语编码。两处引号输出与一处
字符推进修正，由同一套有出处的源级表达式在两平台执行；原缓存 C++、
代码页和字形表保持不变，其他三种语言使用原规则。运行时不加载补丁 EXE/DLL。

安卓 v8 启动配置新增乌克兰语值，保留 v7 中玩家已选的中、日、英语言、
字幕文件 URI 和其他开关。默认游戏语言仍是中文，界面语言与游戏语言分别设置。

## 字幕文件由玩家自己选择

在「字幕来源 → 选择文件」中选作者的 `todokanai/subtitles`，
或者任意文件名的同格式文件。无需改成 YAML，也不读取旁边的 `font.png`；
字形通过现有的离屏系统字体适配器生成。现有 `sub.yaml` 仍可使用。
程序不自动选择、导入或启用补丁字幕，来源 URI 由玩家选择并保存。

两种格式都要求 UTF-8、最多 1 MiB，并在选择和启动时校验。
Todokanai 格式示例：

```text
{
1002 9763 1002 114
0 800 First line^Second line
800 900 Next caption
}
```

头部依次为音频场景、音频编号、PC 剧情场景、PC 行号。后两项校验为
定位元数据，本端以实际语音/音效事件为字幕起点；音效同时匹配当前场景，
并支持场景为 0 的全局音效。每行前两项是起始毫秒与持续毫秒；
`^` 强制换行。较晚字幕在开始时接替尚未结束的前一条，兼容原文件的四处重叠。
不合法的头部、UTF-8、时间、重复音频身份或超限内容明确报错。
外置文件替换整份内置补充字幕，不和内置内容自动混合。

**这份 0.1.5 包附带的补充字幕内容是英文。** 乌克兰语剧情翻译与补充字幕
是两件独立的事；玩家可以编辑该文本为自己的语言，再选择保存后的文件。
完整规则见[外置字幕说明](EXTERNAL_SUBTITLES.md)。

## 检查边界

2026-11-10，本地原包与发布散列一致，439 个 payload 文件及两个安装脚本
匹配公开版本。Microsoft Defender 签名 `1.463.212.0` 对 ZIP、
单独取出的 EXE 与 DLL 均未发现威胁；未执行补丁程序。这是本次检查结果，
不构成绝对无病毒保证。

合成文件/内存检查覆盖主篇与 IC 隔离、资源加载回调、字体和姓名、提示、
文字规则、字幕音频事件、换行、重叠及旧配置迁移。两平台构建同源。
未启动游戏、操作游戏菜单或读取屏幕；完整剧情、实际画面和设备性能仍需实测。
